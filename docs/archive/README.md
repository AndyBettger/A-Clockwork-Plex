# Documentation archive

Welcome to the engineering loft. 🧰

This directory preserves the development history behind **A Clockwork Plex**: experiments, physical-test notes, Stage-C transaction work, superseded designs, roadmap snapshots and other useful archaeology.

It is intentionally **not** part of the normal installation path. If you are installing the appliance for the first time, go back to [`../INSTALL.md`](../INSTALL.md). If you are looking for the current documentation map, use [`../README.md`](../README.md).

## Pre-release engineering snapshot — 22 August 2026

`pre-release-engineering-snapshot-2026-08-22/` is an exact snapshot of the former top-level `docs/` tree immediately before the documentation was reorganised for first-time users.

It includes, among other things:

- the complete Stage-C design/result trail;
- pre-production EQ/DSP laboratory and rehearsal notes;
- earlier roadmap snapshots;
- physical acceptance evidence;
- historical copies of documents that later continued to evolve.

The snapshot is deliberately frozen. Files inside it may describe retired scripts, old service ownership, unfinished work or a next step that was completed long ago. **Do not treat the snapshot as current installation or operating instructions.**

Think of it as the project notebook: very useful when you need to know *why* something ended up the way it did, considerably less useful when you just want the alarm clock to play music before coffee. ☕

Current documentation always wins when it disagrees with the archive.
