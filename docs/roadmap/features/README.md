# Feature roadmaps

These files keep feature-level progress out of the project-wide `ROADMAP.md`.

Use:

- `../ROADMAP.md` for the project order, current focus, branch status and release gate;
- a feature roadmap here for the bounded checklist and accepted/deferred scope;
- `../../development/` for detailed architecture, testing and physical evidence.

Completed feature roadmaps remain as compact accepted records. They are not implementation diaries; detailed chronology belongs in development/evidence or the roadmap history snapshots.
